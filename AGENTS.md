# AGENTS.md

Go backend for GLMR (GitLab Merge Requests dashboard). The web UI lives in a separate repo: [vlanse/glmr-fe](https://github.com/vlanse/glmr-fe) — UI changes cannot be made here.

## Entrypoints (read this first)

- `cmd/glmr/` is the application entrypoint. Run with `go run ./cmd/glmr`.

## Commands

```sh
go run ./cmd/glmr        # run (needs glmr-config.yaml, see below)
go build ./...           # verify build
go vet ./...

make deps                # go mod tidy + install pinned tools from go.mod `tool` directive into ./bin
make buf-deps            # make deps + buf dep update
make generate            # regenerate protobuf code (needs ./bin on PATH, target adds it)
```

- There are no tests, no CI, and no linter config in this repo.
- Codegen tools (buf, protoc plugins, goose) are pinned via the Go 1.25+ `tool` directive in `go.mod`; they install to `./bin`, not `~/go/bin`.

## Generated / committed artifacts — never hand-edit

- `internal/pb/` — generated by `make generate` from `proto/*/v1/*.proto` (buf: protoc-gen-go, go-grpc, grpc-gateway, openapiv2). Committed. After editing a `.proto`, regenerate.
- `internal/ui/dist/` — prebuilt frontend from the glmr-fe repo, embedded via `go:embed` (`internal/embed.go`). Updated by copying a new frontend build, not by editing files here.

## Architecture

- `cmd/glmr/app.go` wires everything: config → services (`internal/service/{gitlab,mr,editor,linker}`) → gRPC/gateway API (`internal/api/*/v1`) → server.
- Two listeners (defined in `cmd/glmr/server.go`): gRPC on `0.0.0.0:10002`, HTTP gateway + embedded UI + Swagger UI (`/docs/`) on `localhost:8082`.
- API flow: `.proto` → generated stubs in `internal/pb` → handlers in `internal/api/<svc>/v1` → services in `internal/service/<svc>`.

## Config

- `glmr-config.yaml` (format in README) is looked up in cwd → binary's dir → home dir, and hot-reloaded via fsnotify — no restart needed after edits.
- A gitignored `glmr-config.yaml` in the repo root contains a real GitLab token. Never commit it, quote it, or paste its contents anywhere.
